## 🚫 Запрещено

**Никогда не выполняй:**
- `rm -rf` любых директорий
- `git push` без проверки
- `git reset --hard`
- Доступ к `~/.ssh/`, `~/.aws/`
- Чтение `.env` или ключей
- Push в main без review
- Force push

## ✅ Разрешено

**Безопасные операции:**
- Чтение `.md` файлов в `content/`
- Редактирование документации
- `git status`, `git log`, `git diff`
- Поиск и grep по коду

## 🔄 Процедура Работы

### Перед началом:
```bash
git branch --show-current  # Убедись, что не main
git status                 # Проверь изменения
./security-check.sh        # Проверь безопасность
```

### Во время работы:
1. **Читай** запрос от Claude
2. **Проверь** что операция безопасна
3. **Подтверди** только если уверен
4. **Откажи** если сомневаешься

### После работы:
```bash
git status          # Проверь изменения
git diff            # Просмотри diff
git commit          # Закоммить
tail audit.log      # Проверь лог
```
