# 🔒 Процедуры Безопасности для Claude Code

## ⚠️ Уровень: СТРОГИЙ

**Все операции требуют ручного подтверждения. Никакого автоматического доступа.**

---

## 📋 Предоперационный Чеклист

### Перед началом работы:

- [ ] Проверить, что находишься в правильной директории
- [ ] Убедиться, что `.env` файл не отслеживается git
- [ ] Проверить `git status` на наличие неожиданных изменений
- [ ] Убедиться, что работаешь в feature branch (не в main!)
- [ ] Проверить, что audit log включен (`.claude/audit.log`)

### Проверка окружения:

```bash
# Выполни перед началом работы:
pwd                                    # Должен быть 12-factor-agents
git status                             # Проверить ветку
git branch --show-current              # Не main!
ls -la .env 2>/dev/null || echo "✅ .env не существует"
```

---

## 🚫 Запрещенные Операции

### Никогда не выполняй без explicit разрешения:

1. **Файловая система:**
   - ❌ `rm -rf` любых директорий
   - ❌ Удаление `.git/`, `node_modules/`
   - ❌ Перезапись `.env`, `*.key`, `*.pem`
   - ❌ Доступ к `~/.ssh/`, `~/.aws/`, `~/.config/`

2. **Git:**
   - ❌ `git push` без проверки изменений
   - ❌ `git reset --hard`
   - ❌ `git clean -fd`
   - ❌ `git rm -rf`
   - ❌ Force push (`git push --force`)

3. **Сеть:**
   - ❌ Запросы к `localhost`, `127.0.0.1`
   - ❌ Доступ к внутренним доменам (`*.internal`, `*.local`)
   - ❌ Отправка данных на внешние серверы

4. **MCP Серверы:**
   - ❌ Запись вне папки `content/`
   - ❌ Чтение `.env`, ключей, токенов
   - ❌ Удаление файлов

## 🔄 Процедура Рабочего Цикла

### 1. Подготовка (Обязательно)

```bash
# 1. Проверь ветку
BRANCH=$(git branch --show-current)
if [ "$BRANCH" = "main" ]; then
    echo "❌ НЕЛЬЗЯ работать в main!"
    exit 1
fi

# 2. Проверь статус
git status

# 3. Убедись, что нет незакоммиченных изменений
if [ -n "$(git status --porcelain)" ]; then
    echo "⚠️ Есть незакоммиченные изменения. Сначала commit или stash."
    git status
fi
```

### 2. Во время работы

**Каждая операция требует:**

1. **Чтение запроса** от Claude
2. **Проверка** что операция безопасна
3. **Подтверждение** если уверен
4. **Отказ** если сомневаешься

**Пример диалога:**
```
Claude: Я хочу удалить файл content/old-file.md

Ты: ❌ НЕТ! Почему удалять? Лучше переименуй или оставь.

Claude: Я хочу создать файл content/new-guide.md

Ты: ✅ ДА, создавай. Это безопасно.
```

### 3. После работы

```bash
# 1. Проверь что изменилось
git status
git diff --stat

# 2. Просмотри изменения
git diff

# 3. Если все ок - коммить
git add .
git commit -m "Описание изменений"

# 4. Проверь audit log
tail -20 .claude/audit.log
```

## 🚨 Процедура Реагирования на Инцидент

### Если что-то пошло не так:

**1. Немедленно останови работу**
```bash
# Не продолжай работу с Claude
# Закрой VS Code если нужно
```

**2. Проверь что произошло**
```bash
# Проверь изменения
git status
git diff HEAD

# Проверь audit log
cat .claude/audit.log | tail -50

# Проверь файлы
ls -la
```

**3. Откати изменения если нужно**
```bash
# Если изменения не закоммичены:
git checkout -- .

# Если закоммичены:
git revert HEAD

# Если push сделан:
# Срочно свяжись с администратором!
```

**4. Задокументируй инцидент**
```bash
# Создай файл инцидента
cat > INCIDENT_$(date +%Y%m%d_%H%M%S).md << 'EOF'
# Инцидент безопасности

## Дата: $(date)
## Описание: [Что произошло]
## Действия: [Какие команды выполнялись]
## Последствия: [Что изменилось]
## Решение: [Как откатили/исправили]
EOF
```

**5. Уведоми команду**
- Slack/email команде безопасности
- Опиши что произошло
- Прикрепи audit log

## 📊 Аудит и Логирование

### Включено по умолчанию:

**Audit log**: `.claude/audit.log`
- Все MCP операции
- Все git команды
- Все изменения файлов
- Время и дата

**Просмотр лога:**
```bash
# Последние 20 операций
tail -20 .claude/audit.log

# Поиск опасных операций
grep -E "(rm|delete|push|reset)" .claude/audit.log

# Статистика за день
grep "$(date +%Y-%m-%d)" .claude/audit.log | wc -l
```

**Ротация логов:**
```bash
# Архивация старых логов
if [ -f .claude/audit.log ]; then
    mv .claude/audit.log .claude/audit_$(date +%Y%m%d).log
    touch .claude/audit.log
fi
```

## 🔐 Процедура Доступа к Секретам

### Если нужен доступ к .env или токенам:

**1. Никогда не показывай Claude:**
```bash
# ❌ НЕ ДЕЛАЙ:
# @filesystem прочитай .env
# @bash cat .env
```

**2. Используй переменные окружения:**
```bash
# ✅ Правильно:
export MY_TOKEN=$(cat .env | grep TOKEN)
# Затем используй $MY_TOKEN в командах
```

**3. Маскируй в выводе:**
```bash
# Если нужно показать что токен есть:
echo "Token exists: ${MY_TOKEN:0:5}..."
# Вывод: Token exists: ghp_1...
```
