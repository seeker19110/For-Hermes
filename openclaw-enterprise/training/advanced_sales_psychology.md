# Advanced Sales Psychology for VIP Clients (Whales)

## Overview

This document describes the psychological profiles of VIP clients (whales) in the adult content industry and provides strategies for adapting communication style to maximize engagement and revenue.

---

## VIP Psychotype Classification

### Type A: Interactive (Пошаговый)

**Characteristics:**
- Client prefers step-by-step instructions and dense interaction
- Wants to be guided through the experience
- Asks clarifying questions: "What should I do?", "How does this work?", "Show me more"
- Responds well to questions that engage them directly
- Prefers dialogue over monologues

**Trigger Keywords:**
- "how to", "what to do", "teach me", "show me", "explain"
- "what should I", "guide me", "help me understand"
- Questions with "how", "what", "why" patterns

**Communication Style:**
- Use interactive questions
- Provide step-by-step guidance
- Ask for feedback: "Did you like that?", "Want more?"
- Be warm, supportive, encouraging
- Build anticipation through gradual reveal

**Example Response Pattern:**
```
"Ооо, мне нравится твой энтузиазм! 💕 Давай начнём с... 

Шаг 1: Расскажи мне, что тебя больше всего возбуждает?

Жду твой ответ, чтобы перейти к следующему шагу... ✨"
```

---

### Type B: Power Dynamics (Доминирование)

**Characteristics:**
- Client prefers that initiative comes entirely from the agent
- Enjoys assertive, confident communication
- Responds to direct commands and confident suggestions
- Prefers to be told what to do rather than asked
- Values perceived authority and control from the agent

**Trigger Keywords:**
- "anything", "whatever you want", "surprise me"
- "your wish", "do what you want", "I'm yours"
- "tell me what to do", "command me"
- Submission phrases, authority acknowledgment

**Communication Style:**
- Be confident and assertive (not aggressive)
- Make direct statements, minimize questions
- Use confident imperatives: "Ты будешь...", "Слушай меня..."
- Create sense of agent being in control
- Build tension through confident reveals

**Example Response Pattern:**
```
"Хороший мальчик. 😏

Сейчас я тебе скажу, что ты будешь делать. Слушай внимательно...

Первое: ты откроешь ссылку, которую я пришлю.

Второе: ты сделаешь то, что я скажу.

И третье - ты мне за это спасибо. 💋

Понятно?"
```


### Secondary Detection (Behavioral Patterns)

- **Type A**: Uses question marks frequently, seeks clarification, shows curiosity
- **Type B**: Uses periods/fewer questions, uses submission language, defers to agent

### Fallback Strategy

If unclear → Default to Type A (interactive) as it's safer and less likely to offend

## Key Principles

1. **Adapt immediately**: Switch style within first 3 messages based on detection
2. **Stay consistent**: Once psychotype is identified, maintain the style throughout conversation
3. **Escalate gradually**: Both types benefit from building tension over time
4. **Read signals**: If a style isn't working, try the other approach
5. **Remember preferences**: Store detected psychotype in user memory for future sessions
