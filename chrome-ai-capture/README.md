# AI Capture Chrome Extension

## Что делает
- `1) Что скачать`:
  - `Design`: полный пакет для реконструкции (HTML/CSS/JS, анимации, токены, скрины desktop+mobile, AI prompt) в `ZIP`.
  - `Knowledge`: очищенный `Markdown` без интерфейсного мусора.
- `2) Глубина`:
  - `Текущая страница`: скачивание + копирование результата в буфер.
  - `Весь сайт`: обход до 10 соседних ссылок, только скачивание файла.
- Галочка `Картинки`:
  - Для `Knowledge` добавляет ссылки на изображения в контент при наличии.
  - Для `Design` добавляет список и попытку скачать файлы изображений в ZIP.

## Установка в Chrome
1. Открой `chrome://extensions/`.
2. Включи `Developer mode`.
3. Нажми `Load unpacked`.
4. Выбери папку `chrome-ai-capture`.

## Быстрый запуск Chrome с этим расширением (macOS)
```bash
open -na "Google Chrome" --args --disable-extensions-except="$(pwd)/chrome-ai-capture" --load-extension="$(pwd)/chrome-ai-capture"
```

## Ограничения
- Deep crawl намеренно ограничен 10 страницами.
- Для крупных сайтов выбираются тематические соседние ссылки, а не полный обход домена.
- Часть внешних CSS может быть недоступна из-за CORS; ссылки на такие стили сохраняются в отчете.
